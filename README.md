# Washing System Automation Project

This repository contains my personal work on building and improving an **industrial washing system** using **CODESYS** and **Structured Text (ST)** programming.  
It is part of my journey in automation software development, combining electrical expertise with modern PLC programming.

## Goals
- Design and implement control logic for a washing system
- Practice Structured Text (ST) programming in CODESYS
- Integrate sensors, actuators, and timing sequences
- Use GitHub for version control and project documentation
- Experiment with AI-assisted coding and workflow optimization

## Notes
This repository is for personal learning and project development.  
It may include test code, prototypes, and documentation of the automation process.
